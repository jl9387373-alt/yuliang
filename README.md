# 余量

给「每月固定生活费」学生的本地预算助手：知道还能花多少、够不够撑到下次到账。余量 = 到账前还能支配的空间。

React 19 + TypeScript + Vite，金额按整数分，数据存 `localStorage`，不上传。

**在线演示：** https://jl9387373-alt.github.io/yuliang/

## 运行

```bash
npm install
npm run dev
```

## 测试与构建

```bash
npm test
npm run build
```
